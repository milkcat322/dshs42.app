최대 힙 · 최소 힙

핵심

  • 최대 힙: 부모 ≥ 자식 (루트 = 최댓값) · 최소 힙: 부모 ≤ 자식
  • 모양은 완전이진트리 → 배열 heap[1..hn] 에 빈칸 없이 저장
  • 부모 i/2 · 왼쪽 자식 i*2 · 오른쪽 자식 i*2+1 (1번부터 써야 계산이 깔끔)
  • hn = 원소 개수 = 마지막 위치의 인덱스

삽입 · 제거

  • 삽입(push): 맨 마지막 칸(heap[++hn])에 넣고 부모와 비교하며 위로 스왑 (부모가 더 크면 끝)
  • 제거(pop): 루트를 꺼내고, 마지막 값을 루트로 올린 뒤(heap[hn--]=0) 자식과 비교하며 아래로 스왑
  • 두 자식 모두 스왑 가능하면 더 큰 자식과 (최소 힙은 더 작은 자식)
  • 둘 다 높이만큼만 움직이므로 O(log n)

시험 포인트

  • 삽입 · 제거 뒤 배열 상태를 쓰는 문제 — 위 플레이어로 직접 넣고 빼며 연습
  • heap[++hn]=x 와 heap[hn++]=x 의 차이, heap[hn--]=0 과 heap[--hn] 의 차이
  • pop 의 반복 조건 i*2 <= hn = 왼쪽 자식이 있는 동안

Union-Find (서로소 집합)

핵심

  • parent[i] = i 의 부모. 처음엔 모두 자기 자신 (parent[i]==i 면 루트)
  • Find(x): 루트를 찾음 · Union(x,y): 두 루트를 찾아 y 쪽 루트를 x 쪽 루트 밑에 붙임
  • 같은 집합인지 = 루트가 같은지
  • MST 의 크루스칼에서 사이클 판별에 씀

경로 압축 · 랭크

  • 한 줄로 길게 이어지면 Find 가 끝까지 올라가야 해서 느림
  • return parent[x] = Find(parent[x]); → 올라가며 지나간 노드를 모두 루트에 바로 붙임 (경로 압축)
  • 크루스칼 코드의 rnk: 높이(랭크)가 낮은 쪽을 높은 쪽 밑에 붙이고, 같으면 붙인 쪽 랭크 +1

이진트리 · 트리 순회

포화 · 완전 이진트리

  • 포화(Perfect): 리프가 아닌 노드는 모두 자식 2개, 모든 리프의 깊이가 같음 → 높이 h 면 노드 2h − 1개
  • 완전(Complete): 마지막 레벨만 빌 수 있고, 비는 곳은 오른쪽부터 (왼쪽부터 차례로 채움)
  • 완전이진트리라서 힙을 배열에 빈칸 없이 넣을 수 있음 · 레벨 k 의 번호는 k … 2k−1 (k = 1, 2, 4, …)

순회 (Root 를 언제 출력하나)

  • 전위 Root → L → R
  • 중위 L → Root → R
  • 후위 L → R → Root
  • 프린트 코드는 a[x][0] 왼쪽 · a[x][1] 오른쪽, 없으면 -1 (또는 0) — 재귀로 그대로 따라감

최소 신장 트리 (MST)

신장 트리

  • n 개 정점을 n−1 개 간선으로 모두 잇고 사이클이 없는 무방향 그래프
  • 최소 신장 트리: 그중 간선 가중치 합이 가장 작은 것

크루스칼 vs 프림

  • 크루스칼 (간선 중심): 가중치 오름차순 정렬 → 사이클이 안 생기면(Union-Find) 추가 → n−1 개면 끝 · O(E log E)
  • 프림 (정점 중심): 시작 정점에서, 트리와 맞닿은 간선 중 가장 가벼운 것으로 정점을 하나씩 붙임 · 우선순위 큐에 -가중치 를 넣어 최소를 먼저 꺼냄
  • 프린트: 크루스칼 O(n log n) · 프림 O(n²) (배열로 할 때)

시험 포인트

  • 크루스칼 코드는 직접 쓰기보다 빈칸(특히 Union-Find 부분 find · unite)으로 나올 듯 — 코드 빈칸 칸의 '크루스칼'
  • 위 그래프에서 간선을 고르는 순서를 손으로 써 보기 (둘 다 합은 31)

DAG 위상정렬

핵심

  • DAG = 방향이 있고 사이클이 없는 그래프 (사이클이 있으면 순서를 못 정함)
  • ind[y] = 진입 차수 (y 보다 먼저 와야 하는 것의 수)
  • 진입 차수 0 인 정점을 큐에 → 꺼낼 때마다 출력하고 다음 정점의 진입 차수 −1 → 0 이 되면 큐에
  • 줄 세우기 = 큐 · 문제집 = 우선순위 큐(-번호 를 넣어 작은 번호부터)

작업 (시험에 낸다고 하심)

  • 작업마다 걸리는 시간 work[i], 먼저 끝나야 하는 작업이 있음 · 동시에 여러 작업 가능
  • d[i] = 작업 i 가 끝나는 가장 이른 시각 · 처음(진입 차수 0)은 d[i] = work[i]
  • x 를 꺼낼 때 다음 작업 y 마다 d[y] = max(d[y], d[x] + work[y])
  • 답 = d 의 최댓값 (아래 예제: 23)

최단거리 · 다익스트라 · 벨만포드

다익스트라

  • 간선이 모두 0 이상일 때 · 시작점 하나에서 모든 정점까지
  • 아직 확정 안 된 정점 중 dist 가 가장 작은 x 를 확정(check[x]=true) → x 에서 나가는 간선으로 dist 갱신 · n−1 번
  • 프린트 코드는 최솟값을 배열에서 찾아서 O(n²)
  • 경로 출력: 갱신할 때 from[y] = x → end 에서 거꾸로 따라가며 stack 에 넣고 꺼냄

벨만포드

  • 음수 간선이 있어도 됨 · 모든 간선으로 갱신하기를 n 번
  • n−1 번이면 최단거리가 끝나야 하는데 n 번째에도 갱신되면 음수 사이클
  • dist[x] != inf 인 간선만 씀 (아직 못 간 곳에서 출발 X)
  • 타임머신: 음수 사이클이면 -1 · 웜홀: 도로는 양방향, 웜홀은 cost *= -1
