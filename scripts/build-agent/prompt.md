## 꼭 지킬 것
- 이 폴더의 `CLAUDE.md` 규칙을 따른다. 처음에 `CLAUDE.md` 의 `주의할 점` 중 맡은 일과 관계있는 줄만 찾아 읽는다 (전체를 다 읽지 않아도 된다).
- 필요한 파일만 Grep 으로 찾아 필요한 부분만 Read 한다. `dshs-study.js` · `admin/admin.js` · `index.html` 은 크므로 통째로 읽지 않는다.
- 맡은 일만 한다. 관계없는 정리 · 리팩터링 · 이름 바꾸기를 하지 않는다.
- git commit · push 는 하지 않는다 (실행 스크립트가 한다). `sw.js` 의 `CACHE` 도 건드리지 않는다 (스크립트가 맞춘다).
- DB(Supabase) 를 직접 바꿀 수 없다. 표 · 함수 · 권한(RLS)을 바꿔야만 하는 일이면 `.sql` 파일에 바꿀 내용을 적어 두고 결과를 `needs_human` 으로 한다.
- 비밀값(키 · 비밀번호 · 토큰)을 코드에 넣지 않는다. 이름 · 학번 같은 학생 정보를 새로 보여 주거나 밖으로 보내지 않는다.
- 학생에게 보이는 기능을 바꿨으면 `updates.js` 맨 위에 학생이 읽을 말로 항목을 더한다 (개발 용어 없이, 새 기능은 `major: true`).
- 관리자 기능은 `admin/admin.js` 에만 넣는다. 학생 사이트에 관리자 코드를 넣지 않는다.
- 다 고친 뒤 바꾼 `.js` 파일마다 `node --check` 로 문법을 확인한다. `dshs-study.js` 를 고쳤으면 맨 끝 `init();` 이 그대로 있는지 확인한다.

## 마지막 줄
일을 마치면 맨 마지막 줄에 아래 형식 한 줄만 출력한다 (줄바꿈 없이 JSON 한 개).
`RESULT {"status":"review","summary":"관리자가 읽을 2~4문장 요약: 무엇을 어디에 어떻게 바꿨고, 미리보기에서 무엇을 눌러 보면 되는지"}`
사람이 해야 할 일(DB 변경 등)이 남았거나 맡은 일을 할 수 없으면 `"status":"needs_human"` 으로 하고 summary 에 이유를 쓴다.
